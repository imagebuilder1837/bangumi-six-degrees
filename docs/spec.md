# 行为规格

领域名称见 [GLOSSARY.md](../GLOSSARY.md)。

## 路径与证明

- 支持无向关联、单向好友、双向好友。返回任意一条跳数最少的路径，不枚举所有等长路径；相同有效端点为零跳，六跳不是上限。
- 使用双向广搜，在整层边界比较预计访问成本选择扩展方向；成本只影响访问顺序，不影响最短性证明。
- 只有候选长度不超过两个搜索方向尚未展开边界的距离之和时，才确认最短；不在首次相遇时无条件结束。某侧完整穷尽可证明不可达。
- 缺少列表是未知，不是空集合。证据不足不展示候选路径；完整证明不可达则明确展示。停止、请求失败和观察不足均不是不可达。

## 关系观察视图

- 证明相对于本次纳入的、完成必要边界验证的关系观察视图，不承诺统一时刻的全站快照，亦不承诺整个数据库所有记录合并后的全图。缓存不因年龄失效。
- 同一有向关系的正反方向证据按本轮观察完成顺序取后一份，不用旧缓存补齐证明。
- 已展开节点受新观察影响时，更新其邻接关系，仅使依赖失效边的父链子树失效，并从受影响边界重新松弛。其他距离、邻接信息和本轮请求结果保留；影响范围可以沿依赖传播。
- 已识别的原站数据错误按无效节点排除；普通 HTTP、网络、身份或结构错误不归入无效节点。仅有昵称“[已注销]”不足以排除用户。
- 整个列表不可访问须严格匹配共享库的专用错误声明条件。合法列表中缺失身份的标准条目只丢弃该条目，保留其他成员；无法将未知身份映射为其他列表中的某个用户。已识别用户条目去重。
- 中间用户采用原站列表链接标识，不额外访问主页归一身份。列表结构或分页无法确认时失败，不以部分列表冒充完整关系。

## 缓存与资料

- 使用 vendor 中的 bangumi-relationship-store；数据库只存关系观察和展示资料，不存搜索状态或路径结果。共享范围受同 origin、浏览器及存储分区限制。
- 每个有效完整方向列表独立入库，不以全次搜索成功为条件。普通请求失败不生成空观察、不覆盖旧记录。写入失败不使网络路径失效；成本估算缓存读取失败也不阻止网络搜索。
- 每次探索均重新从网络取得关系观察；旧关系缓存仅辅助扩展成本估算，不进入路径证明。页面首次打开不搜索，关闭重开复用当前会话，不重新取数。
- 头像、昵称从本轮端点身份及关系列表扫描取得，可随关系存入共享库；不使用旧缓存资料展示路径，不逐个补抓中间用户主页。缺少资料时用用户标识和默认头像。
- 界面仅引导输入用户标识，不提示其他输入形式；实现仍接受数字 ID 或三个 Bangumi 域名的主页链接。用主页身份及规范关系链接归一，不直接拼接数字 ID 的关系子路由。输入失焦及快捷填入时确认身份并更新头像与输入框上方昵称，长昵称省略显示且悬停可查看全文；已确认用户的端点头像可在新标签打开对应规范主页，未确认时无链接。旧异步结果不得覆盖新输入。

## 请求

- 本组件当前页面内，所有资料和关系请求共用最多四并发的队列，使用同源凭据。
- 单次请求含正文读取的超时为 30 秒。网络、正文读取、408、429、5xx 错误最多重试两次，分别退避一秒、两秒；普通其他 HTTP 错误、被拒绝的跳转和解析错误不重试。
- 随机候选和手动输入共用主页归一：仅允许同源、无查询参数或片段的合法用户主页跳转，跳转目标用户标识须与正文身份及规范好友链接一致；无跳转的数字主页仍可按正文归一。不额外查询 UID；关系列表及分页不允许跳转。拒绝的跳转终止操作并保留原输入，不自动换人；仅明确的同源登录目标提示检查登录，其他目标或无法识别的页面使用中性错误。
- 429 的 Retry-After 约束所有后续新请求与重试，取全局截止时间与当前退避要求的较大者。缺少有效值时等待 60 秒；429 仍计入重试次数。
- 停止须使排队、退避、请求和正文读取及时结束，即使底层传输不响应取消。已经提交的缓存不回滚；旧任务收尾不得覆盖新任务。

## 交互

- 仅在三个域名的用户主页 network_service 末尾挂载入口，自己和其他用户主页均支持；紫色 SixDegrees 牌子后接“六度分隔”链接，不再挂载悬浮入口。
- 弹窗桌面顶部为两个端点，中间是关系模式及对应连线，下方可交换端点；窄屏上下排列。首次起点填入当前主页用户、终点留空，无历史条件或结果；关系模式默认双向好友，选项从上到下为双向好友、单向好友、无向关联。每个端点提供“填入自己”和“随机班友”；无法识别登录用户时仅禁用“填入自己”。
- 修改端点、交换或切换模式立即清空结果及旧状态提示，不自动搜索；重新探索时不保留上次结果。运行时锁定条件，保留停止能力。关闭只隐藏，搜索继续；重开复用，完成不自动弹窗。
- 中部展示状态和最终路径；长路径横向滚动，用户节点可打开主页。不给搜索编造百分比，不展示未证明的当前候选。超过六跳显示轻量彩蛋。
- 探索和停止按钮放右下角；原站粉色基调、明暗主题、窄屏布局、键盘关闭及焦点约束均适配。减少动态效果偏好下禁用动画。
- 不持久化搜索条件或路径；升级时仅清理本组件原有成功条件记录，不清除共享关系库或其他存储。

## 随机班友

- 随机抽取数字主页定位符，归一为用户标识后校验两个方向的完整关系列表。合法空列表、昵称为“[已注销]”但列表正常均可通过；不要求活跃、有好友或可达，沿用既有缺失标识条目容错。
- 避开当前两个端点，仅替换点击侧的端点，不自动探索。明确不存在或关系列表不可用则继续抽取，不限制候选次数；普通网络、限流重试耗尽及结构错误结束本次抽取，保留原输入。过程可停止；手输、交换或再次抽取使旧操作失效，关闭仅隐藏。
- 校验中完成的方向观察可独立提交共享库，但后续探索仍重新网络取数，不复用校验观察作证明。
- 当前抽取使用已有范围，不等待后台更新；缺少或无法使用范围记录时采用内置观测基线。后台按记录时间差估算增长，倍增寻找失败上界，再二分到区间宽度小于 10000；忽略高位账号空洞，因此范围只是启发式估计。
- 后台普通请求失败或取消不覆盖已有范围；成功后保存范围、已成功解析的高位数字定位符及时间，供后续抽取使用。后台与其他请求共用队列和限流，避免短时间反复探测；界面不展示范围或算法说明。
